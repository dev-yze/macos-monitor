# Apple Silicon 菜单栏能耗监控工具设计

## 目标

构建一个轻量级 macOS 菜单栏 App，专门面向 Apple Silicon Mac，首要适配用户的 MacBook Pro M5 Pro。App 应该安静地常驻菜单栏，在菜单栏中显示一个最关键的实时指标，并在点击后打开一个紧凑的 SwiftUI 面板，用于查看 CPU、GPU、内存、外部存储、显示器刷新率、电池功率和温度数据。

第一版优先保证在本机上实用、稳定、长期可运行，不追求广泛硬件兼容。Intel Mac 不在第一版范围内。

## 产品范围

MVP 是一个原生 macOS App，使用 Swift 和 SwiftUI 开发。它通过 `MenuBarExtra` 常驻菜单栏，并在 App 进程内通过一组职责清晰的采集器收集系统指标。

菜单栏项目显示当前估算整机功耗或主芯片温度，用户后续可以切换。弹出面板显示：

- CPU 使用率。
- GPU 指标；优先显示从 `powermetrics` 解析出的数据，拿不到时显示不可用状态。
- 内存使用量、swap 和内存压力。
- 电池充电或放电功率。
- 从 Apple Silicon 系统输出中解析出的温度读数。
- 外部存储容量和读写活动。
- 已连接显示器的刷新率。
- 最近更新时间和各采集器状态。

默认采样间隔为 2 秒。App 在内存中保留最近约 5 分钟的采样，用于绘制小型趋势图。MVP 不把历史数据写入磁盘。

## 权限

App 可以为了高级指标请求管理员权限。MVP 使用 `/usr/bin/powermetrics` 获取 Apple Silicon 的能耗和温度数据，因为它比普通公开高层 API 更容易获得功耗、GPU、频率和温度信息。

第一版可以在用户开启高级监控时提示输入管理员密码。长期运行的 privileged helper 暂时延后，等核心数据源和 UI 证明有价值之后再做。

## 架构

### App 外壳

`MacOSMonitorApp` 负责 SwiftUI App 生命周期，并注册 `MenuBarExtra`。它创建共享的 `MetricsStore`，并注入给各个视图使用。

### 状态存储

`MetricsStore` 是 UI 订阅的统一可观察模型。它保存最新指标快照、短期内存历史、采集器状态、权限状态，以及菜单栏显示指标、采样间隔等用户设置。

### 采集器

每个采集器只负责一类数据：

- `PowermetricsCollector`：启动 `powermetrics`，读取采样输出，并返回解析后的功耗、GPU、CPU 频率和温度指标。
- `SystemStatsCollector`：读取 CPU 负载、内存压力、内存使用量、swap 和系统级 host stats。
- `StorageCollector`：列出已挂载的外部卷，采集容量和磁盘 I/O 增量。
- `DisplayCollector`：读取当前显示器刷新率和基础显示器信息。
- `BatteryCollector`：读取电池充放电状态、可用的电流或功率数据，以及循环次数等元数据。

采集器在某项指标不可用时应该显式返回不可用状态，而不是让整个 App 失败。

### 解析器

解析逻辑和进程执行逻辑分离。`PowermetricsParser` 将原始文本转换成类型化指标。解析器测试使用捕获的样本文本，这样后续可以针对用户的 M5 Pro 输出调整解析逻辑，而不影响 UI 代码。

### UI

UI 保持紧凑、直接、偏工具属性：

- 菜单栏标签：一个指标加简短单位，例如 `18 W` 或 `62 C`。
- 弹出面板顶部：当前温度/功耗摘要和最近更新时间。
- 指标区块：CPU、GPU、内存、电池、存储、显示器、温度。
- 设置控件：采样间隔、菜单栏显示指标、高级监控开关。
- 状态提示：清楚显示缺少权限、指标不可用或采集器失败等情况。

App 不做落地页，打开后直接进入监控界面。

## 数据流

1. App 启动并初始化采集器。
2. 基础采集器在不需要管理员权限的情况下立即开始工作。
3. 如果启用高级监控，App 使用管理员授权启动 `powermetrics`。
4. 各采集器产出局部指标快照。
5. `MetricsStore` 合并快照、更新历史数据，并发布给 SwiftUI。
6. UI 渲染当前值、趋势和不可用状态。

## 错误处理

某个采集器失败时，App 应该继续运行。失败信息通过采集器状态展示，而不是导致 App 崩溃。

预期失败情况包括：

- 用户拒绝管理员权限。
- `powermetrics` 输出格式和解析器预期不一致。
- 某个 macOS 版本上 GPU 或温度字段不可用。
- 当前没有外部存储。
- 弹出面板打开期间，磁盘或显示器被拔出。

`MetricsStore` 可以短暂保留最后一个有效值，但在更新停止后必须标记为过期数据。

## 测试

第一版实现应包含聚焦的测试：

- `powermetrics` 文本解析。
- `MetricsStore` 的快照合并逻辑。
- 瓦特、摄氏度、百分比、字节和吞吐量等单位格式化。

手动验证包括：

- App 能作为菜单栏 App 启动。
- 不授予管理员权限时，基础指标可以显示。
- 授予权限后，高级指标可以显示。
- 拒绝权限不会导致 App 崩溃。
- 没有外部存储时，界面显示干净。
- 空闲采样时不会明显拉高 CPU 使用率。

## 延后事项

以下内容不属于 MVP：

- Intel Mac 支持。
- 持久化历史数据库。
- 开机登录自动启动。
- 签名和 notarization 分发包。
- privileged helper 或 LaunchDaemon。
- 按 App 统计 FPS。
- 深度游戏或 Metal 进程插桩。

## 已确认决策

- 目标平台：仅 Apple Silicon macOS。
- 初始产品形态：轻量级菜单栏 App。
- 权限模型：接受为了高级指标请求管理员权限。
- 实现路径：原生 Swift/SwiftUI App，MVP 直接集成 `powermetrics`，暂不做独立 helper。
